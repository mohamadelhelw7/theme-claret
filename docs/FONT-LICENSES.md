# Bundled font licenses

Claret's default fonts, Newsreader and Red Hat Text, are served by Shopify's font library through the font pickers in Theme settings → Typography, so they are not bundled in this theme and need no separate license file.

Folio bundles these typefaces in `assets/`. All of them are published on Google Fonts under the SIL Open Font License, Version 1.1. That license allows bundling and redistribution with software, including commercial themes. The fonts may not be sold on their own.

| Files | Typeface | License |
| --- | --- | --- |
| `instrument-serif-*.woff2` | Instrument Serif (regular and italic) | SIL OFL 1.1 |
| `inter-tight-*.woff2` | Inter Tight (variable weight) | SIL OFL 1.1 |
| `noto-naskh-arabic-arabic.woff2` | Noto Naskh Arabic (variable weight) | SIL OFL 1.1 |
| `noto-sans-arabic-arabic.woff2` | Noto Sans Arabic (variable weight) | SIL OFL 1.1 |

Each file keeps the copyright notice embedded by its authors. The files are the subsets served by Google Fonts.

Full license text: https://openfontlicense.org/open-font-license-official-text/
